# StallBox Frontend Setup

## Install dependencies

cd frontend

npm install

---

# Environment Setup

Create:

.env

Copy from:

.env.example

Example:

VITE_API_URL=http://localhost:5000/api

---

# Run Project

npm run dev

Frontend runs at:

http://localhost:5173

---
